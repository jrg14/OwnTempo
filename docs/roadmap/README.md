# Roadmap

El roadmap contiene únicamente conceptos de producto: qué funcionalidades queremos
que tenga OwnTempo, en qué orden general se abordarán y cuál es su estado.

Los detalles técnicos y las tareas de desarrollo pertenecen a [`../plans/`](../plans/).

## Estados

- `propuesta`: funcionalidad candidata aún no priorizada.
- `planificada`: aceptada para una fase del producto.
- `en desarrollo`: implementación activa.
- `bloqueada`: no puede avanzar por una dependencia o decisión pendiente.
- `completada`: disponible y verificada.
- `descartada`: no se desarrollará por ahora.
