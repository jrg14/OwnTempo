# Planes de implementación

Esta carpeta transforma funcionalidades aceptadas del roadmap en planes técnicos
ejecutables. Los planes pueden evolucionar durante el desarrollo y deben reflejar
dependencias, modelo de datos, API, permisos, pruebas y criterios de aceptación.

## Planes iniciales

1. [Usuarios y autenticación doméstica](identity-and-authentication.md)
2. [Espacios y pertenencia](personal-space.md)
3. [Espacios, miembros y permisos](spaces-and-memberships.md)
4. [Arquitectura modular](modular-architecture.md)
5. [PWA y despliegue doméstico](pwa-and-home-deployment.md)

Los planes específicos de calendario, tareas, listas de la compra y gastos se
redactarán antes de comenzar cada módulo, una vez estabilizada la base común.
