# Documentación de OwnTempo

Esta carpeta reúne la documentación funcional y de planificación del proyecto.

## Secciones

- [`ideas/`](ideas/): visión de producto, conceptos generales y propuestas todavía abiertas.
- [`roadmap/`](roadmap/): funcionalidades deseadas, prioridad conceptual y estado de producto.
- [`plans/`](plans/): planes técnicos para implementar las funcionalidades del roadmap.
- [`features/`](features/): explicación funcional y técnica de lo que ya está implementado.

## Flujo documental

Una propuesta nace en `ideas`, pasa al `roadmap` cuando se decide incorporarla al
producto y obtiene un documento en `plans` antes de desarrollarse. Cuando su
implementación termina, su funcionamiento real se documenta en `features`.
